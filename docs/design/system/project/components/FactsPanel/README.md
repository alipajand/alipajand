# FactsPanel

The case study's facts: role and timeframe side by side, the stack as chips across the full width, and one light row per live link.

- Without a timeframe, the facts stack in one column (`.facts--stack`).
- The live rows are the page's only light buttons: `line` ground with `ink` text, showing the host in mono.
- When a project has no screenshots, the panel moves into the intro's right-hand column.
