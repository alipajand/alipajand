# CaseSection

One numbered section of a case study: a sticky bracketed index and an uppercase title on the left, and the body as stacked hairline rows on the right.

- Body blocks are a `lead` paragraph, an `items` list, `cells` (a two-column grid for What I built), decision cards or a diagram. Each block is its own row.
- The left column sticks below the chapter rail on desktop. On phones the title sits above the body.
- Section order follows the site's case study page: Context, Problem, My role, What I built, Technical decisions, UX and detail decisions, Interface evidence, Outcome, What I would improve, Related work.
