Featured

The three case studies with the most evidence behind them.

  1. 2026–Present Senior Product Engineer

    LedgerGuard case study

    Full-Stack AI Contract Intelligence

    Built alone across the Next.js product, Fastify API, PostgreSQL schema, and a queue-backed document pipeline, with AI-suggested values kept apart from confirmed contract data until someone reviews them.

    Key decision

    Keep deterministic contract data and API rules in Node.js/Fastify while isolating probabilistic extraction in the Python worker behind explicit job contracts.

  2. 2024–2026 Senior Frontend Engineer

    AlwaysGeeky Games case study

    Shared Design System & Frontend Standards

    Built and owned the shared React and TypeScript library four product surfaces were built on, with Storybook as the contract and CI gates that caught drift before it shipped.

    Key decision

    Treat component APIs as the contract, and Storybook as where that contract is written down, rather than as documentation produced after the fact.

  3. 2022–2023 Senior Frontend Engineer

    Emplifi case study

    Enterprise Analytics

    Dense D3.js analytics modules assembled from shared accessible components, with rendering work profiled on the embedded mobile-webview path where the cost showed up.

    Key decision

    Use D3.js for chart behavior and React for surrounding product composition rather than trying to collapse the whole dashboard into a single abstraction.
